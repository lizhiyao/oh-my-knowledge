## 验收发现并修复的展示问题

Session 的一条陈述保存为 `relation: 在状态更新时新增计数`、`polarity: negative`，含义是状态更新不新增计数。原界面把否定标记放进默认折叠的“陈述分类与时间”，默认标题却显示“Session 在状态更新时新增计数”。两种窗口高度均复现，不依赖截图。

修复直接读取已保存的 polarity，在陈述标题显示“否定陈述”（英文 `Negative claim`），分类详情仍可展开。没有通过字符串猜测否定，不改关系、模型输出、存储或提示词。中英文、含／不含对象、文本转义与肯定反例有渲染回归覆盖；Chrome 复验默认标题可见否定标记。两条此前记录的区别关系措辞问题仍保留，未顺手改写知识。
