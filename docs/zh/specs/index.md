# 领域规范

本目录规定实现必须满足的行为、不变量、数据边界和验收。概念先读[原理](../explanation/index.md)，用户操作从[文档首页](../README.md)进入。按受影响领域选择规范，不必先读整套 Core 或历史 RFC。

## 选择领域

| 领域 | 规定什么 |
|---|---|
| [共享命名与存储](shared/index.md) | 约束跨领域的名称、存储位置和写入边界。 |
| [实体身份与提取](entities/index.md) | 规定来源对象、原文提及、纠正和提炼质量的验收。 |
| [知识建设与维护](knowledge/index.md) | 规定内容修订、组织关联与载体维护的一致性。 |
| [受控评测](evaluation/index.md) | 规定测量内核、产品接线、证据和结论。 |
| [观测与复核](observe/index.md) | 规定从真实记录派生的信号与有效复核语义。 |
| [Studio 宿主与数据流](studio/index.md) | 规定页面宿主、查询、缓存与刷新。 |

## 阅读与维护边界

- 当前规范描述现行规则；未交付能力必须单独标明，不用存在字段或界面推定验收。
- 独立质量复核、真实性和实际收益有各自证据，不能用功能完成代替。
- 当前文档只保留最新有效规则和必要限制。旧提案、已替代设计与逐版本试验过程退出文档站；必要原始证据由固定 Git 版本、Issue 或 PR 追溯。
- 概念、操作步骤和完整字段分别由 explanation、guides 和 reference 拥有，跨层链接，不复制第二份。

中英来源逐项镜像。目录服务仓库阅读；文档站保留现行页面的公开地址。历史文件和冻结证据不因整理变成当前能力承诺。
