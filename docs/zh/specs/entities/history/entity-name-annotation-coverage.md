## 范围与规则

本轮承接[首例后停止的 v11 诊断](./entity-extraction-v11-boundary-diagnostic.md)，不只补“已发布 r2”。逐项读取所有消息、旧边界、所绑身份及上下文，检查类型词、冠词／指示词、所有者、位置和时间限定的连续名词描述。新增备选保留来源字节，为每个 quote 独立计算 occurrence 与 UTF-16 区间；它们仍指同一次出现的同一对象，不移用别处名称。

| 来源类别 | 新增备选示例 | 仍排除的错误绑定或扩展 |
|---|---|---|
| 项目及所属文件 | 项目 Pavo；项目 Pavo 的 a.md | 整个文件短语绑定为项目。 |
| 类型与英文实例 | Rill 调度器；Its test instance `sieve/dev01`；Plan P8 | 整条定义／执行陈述；并列部署实例列表绑定单体。 |
| 类别、位置与指代 | 键盘这一类物品；桌上的这把键盘；本次说的这家店；这里的栈 | 讨论或消歧谓词；将类别与具体物品合并。 |
| 活动与发布限定 | 昨天的更新活动 U1；已发布 r2 | 今天计划执行 U2；main 上的改造绑定为代码状态。 |
| 所有者限定字段 | 客户端 L 的 errorStatus；服务 S 的 enabled 字段 | 绑定到客户端／服务本身；包含等号、值、环境赋值的整句。 |

属性归属由短语实际中心决定，不按“的”“上的”机械裁剪。文件／字段的所有者限定可以帮助指出对象，与所有者短提及允许重叠；属性短语不能反过来作为所有者的别名。谓词、动作、赋值、成员列表及属性头与对象名分别核对。

## 修订与留痕

当前语料为 `omk-entity-quality/v12`，指南为 `omk-entity-annotation/v10`；提示词保持 `knowledge-extraction-v11`，检查算法保持 v4。来源文本／角色／限制、实体身份与层次、关键提及身份／数量、知识角色、语义标准、项目／会话分组及 split 全部保持不变（58 开发／2 预留验证）。旧备选不删除，只在新副本增加已复核边界并补充理由；旧 v11 语料原字节保留。

[下载逐例审核 JSON](/entity-name-annotation-v12-audit.json)：全部 60 例及 199 个复核提及 ID、来源摘要、每项增加的原文／位置／理由和每例一个排除示例。增加 32 个备选的生产接纳及定位回归通过；60 个排除示例即使是合法原文引用，也不作为所绑关键提及的精确命中。程序不新增自动裁剪、词尾正则、宽跨度容忍或语义猜测。

语料／指南身份与编译后的工具摘要改变，属于 `BREAKING-COMPARABILITY`；生产提示词原字节、检查算法、响应 v4／实体与知识历史 v2／运行 v4 保持不变，无迁移。当前工具仅接纳 v12 语料，不新增旧版本兼容读取器；历史报告审计只读原冻结形状，旧结果按旧构建复现。
