# 实体提取 v12：两窗口定向回归

## 结论

**库、适配类与版本身份符合本例自审预期，但两处必须保留的 Session 提及遗漏，本批仍需改进。** 2026-10-11 获批的两窗口计划实际执行了一次 Codex `gpt-6.1-sol` 调用。真实窗口返回 18 个实体、21 处提及、两个知识候选和六条陈述，结构无拒绝；逐项自审发现表格与末段的两个目标提及都没有输出。按冻结停止规则，不执行合成窗口，剩余一次额度关闭。

本例九项非穷尽对象预期均找到且层次符合；唯一必需配置知识保留精确字符串值、所属、范围与来源理由。**实体已找到、知识内容完整或引用覆盖，不代替关键提及覆盖。** 不将遗漏后的“没有错误理由”判为理由修复通过。结论为 `needs_improvement`；作者自审不是独立证据，`goldReady=false`。
