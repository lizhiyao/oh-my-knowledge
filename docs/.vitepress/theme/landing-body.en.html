Follow the workflow to your first step

  1. Read records and sources

    Start Studio and open an existing Codex conversation at the URL returned by the command. This makes no model call. If no records exist, start with source and collection guidance.

    omk studio

  2. Review, accumulate, and revise

    Choose a conversation and turns, review the material to send, then extract candidates. This calls a model and requires an authenticated runtime. Review conditions and evidence; retain or discard with reasons and explicitly link sources to accumulate knowledge.

  3. Review references, then save a version

    Artifact generation makes no additional model call. When knowledge changes, compare old references with current revisions and retain decisions. Explicitly select and save a new version; old content and references remain readable.
