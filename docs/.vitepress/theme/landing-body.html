验证 Agent 是否真的把任务做对了

从固定文件快照执行，采集修改并独立验收；失败、超时或取消也保留声明文件和部分日志。

带 npm 依赖的购物车案例中，真实 Codex treatment 只修改目标源码，六项验收全部通过；要求不编辑的负对照通过三项。案例记录了模型、用量、耗时与接入步骤。

这是一次链路验证，不证明知识版本的普遍收益。任务与验收程序必须可信，工作区副本不是安全沙箱；原始产物和日志可能包含敏感内容。

从证据到改动，每一步都有边界

知识内容是一条事实、经验或方法；知识载体是承载它们的 prompt、文档或 skill。提炼产生待复核内容，人工形成载体改动后再评测；保留知识、采纳改动与发布版本是不同决定。
