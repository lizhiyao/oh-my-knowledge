# Entity extraction: evidence and limits

Entities organize the objects described by knowledge; identifying an entity does not verify a knowledge claim. Start with [How OMK understands knowledge](../../explanation/knowledge.md) for the concept definitions. This page collects current specifications and their capability limits.
