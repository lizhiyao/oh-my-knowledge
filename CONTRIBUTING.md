# Contributing

The contributor guide lives on the documentation site, in both languages:

- English: [docs/guides/contributing.md](./docs/guides/contributing.md)
- 简体中文: [docs/zh/guides/contributing.md](./docs/zh/guides/contributing.md)

This file exists because GitHub surfaces it when you open a pull request. It is a pointer, not a second copy: the branch model, local gates, release process and every command are on the linked page, and only one place holds them.

Before reviewing, or being reviewed, read [`CODE_REVIEW.md`](./CODE_REVIEW.md) for the risk levels, review dimensions and the definition of done (that playbook is maintained in Chinese only).
